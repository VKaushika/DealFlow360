# DealFlow360

DealFlow360 is an intelligent, self-governing B2B Sales Operations Platform.

The platform is designed to manage the complete deal lifecycle:

Customer
→ Quotation
→ Discount Evaluation
→ Approval
→ Fulfillment
→ Billing
→ Negotiation
→ Payment
→ Deal Health

## Hour 1 — Foundation

This first milestone establishes the project foundation:

- Node.js backend
- Express.js REST API
- TypeScript
- MongoDB Local
- Mongoose ODM
- Environment configuration
- Health-check API
- Initial User model
- Error handling
- CORS configuration
- Seed structure
